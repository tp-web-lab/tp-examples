# Identités remarquables
Dans cette section, on cherche à vérifier géométriquement les identités remarquables :

- [Carré d’une somme](identities/square-sum.md) : :tp-math:`(a+b)^2 = a^2 + 2ab + b^2`{}
- [Carré d’une différence](identities/square-diff.md) : :tp-math:`(a-b)^2 = a^2 -2ab + b^2`{}
- [Différence de deux carrés](identities/diff-squares.md) : :tp-math:`a^2 - b^2 = (a+b)(a-b)`{}
