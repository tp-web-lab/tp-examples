## Gestes essentiels

| Action | À essayer |
| --- | --- |
| Choisir un outil | Son bouton devient plein et son aide apparaît dans un callout. |
| Sélectionner des points ou côtés | Cliquer sur la figure ou dans la liste des objets. |
| Move | Déplacer un point libre, un point attaché ou une indication de mesure. |
| Pan view / molette | Déplacer la vue ; Maj + molette décale horizontalement. |
| Grid / zoom / Fit | Vérifier une grille sans axes ; changer le cadrage sans changer les mesures. |
| Measure angle | Sélectionner deux côtés : arc avec valeur, carré sans valeur pour 90°. Trois points donnent une annotation numérique. |
| Tab / Maj+Tab | Parcourir les boutons et champs ; Entrée ou Espace active un bouton. |
| Flèches sur la figure | Déplacer le point ou l’indication sélectionnée ; Maj réduit le pas. |
| Construction source | Load ouvre un .txt ; Save et Save as enregistrent le texte ; Apply construction applique les modifications. |
| Save image | Enregistrer la vue en SVG, PNG ou WebP. |
| Undo / Redo | Annuler puis rétablir une action. |

## Essayer avant de regarder

Chaque atelier propose une figure de départ et un corrigé replié. Le corrigé peut contenir des supports masqués. Pour les retrouver, choisir l’objet dans la liste puis Style > solid. Une construction qui devient impossible est signalée comme indéfinie ; ramener les supports à une position valide doit la restaurer.

## Noter ce que l’on observe

Pour chaque atelier, noter : navigateur, page, geste réalisé, résultat attendu, résultat observé. Si un problème apparaît, enregistrer le .txt et une image. La [page bilan](bilan.md) fournit une liste de vérifications.
