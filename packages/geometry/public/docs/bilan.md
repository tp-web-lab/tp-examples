# Bilan des vérifications

Ce carnet sert à tester le composant ; une case non vérifiée ne vaut pas validation automatique.

| Domaine | Vérification à effectuer |
| --- | --- |
| Dépendances | Déplacer chaque point de départ ; les objets construits doivent suivre. |
| Cas limites | Confondre temporairement deux points, puis les séparer ; vérifier disparition et retour des objets indéfinis. |
| Mesures | Vérifier longueurs, aires, angle droit et angle oblique ; déplacer leurs étiquettes. |
| Clavier | Tab, Maj+Tab, Entrée, Espace, flèches, Maj+flèches et Échap. |
| Outils | Bouton actif plein et aide correspondant à l’action choisie. |
| Fichiers | Save, Save as, Load, fichier invalide, annulation du sélecteur et conservation du dessin. |
| Source | Modifier puis Apply construction ; vérifier les noms dans la liste. |
| Aspect | Couleurs, styles, objets masqués et exports SVG/PNG/WebP. |
| Vue | Défilement, zoom et grille ; une liste d’objets longue doit agrandir le dessin vers le bas sans changer les figures. |
| Historique | Undo/Redo après création, déplacement, suppression et chargement. |
| built-in | Dans la dernière section, ajouter directement un carré, une parallèle ou une bissectrice. |
| Mathématiques | Distinguer la preuve de la mesure et l’heptagone approché des polygones exacts. |
