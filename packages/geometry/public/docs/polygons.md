# Polygones réguliers

Un polygone régulier est un polygone convexe, à la fois équilatéral (tous ses côtés ont la même longueur) et équiangle (tous ses angles intérieurs ont la même mesure).

Cercle circonscrit 
: Tous les sommets d'un polygone régulier touchent un même cercle unique.

Angle au centre :tp-math:`\alpha`{}
: Calculé par la formule :tp-math:`\displaystyle \frac{360}{n}`{}, où n est le nombre de côtés.

Angle intérieur :tp-math:`\beta`{}
: Calculé par la formule :tp-math:`\displaystyle 180-\frac{360}{n}`{}, où n est le nombre de côtés.

Symétrie 
: Un polygone régulier possède autant d'axes de symétrie que de côtés (:tp-math:`n`{}).
