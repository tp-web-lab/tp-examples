Title
: Fonctions usuelles

Answers
: 
  1. nulle
  2. :tp-math:`f'(x) = a`{}


Form
:
  1. Une fonction est constante sur l'intervalle :tp-math:`I`{} :tp-math:`\Leftrightarrow`{} sa dérivée est <tp-blank></tp-blank> sur :tp-math:`I`{}.

  2. Une fonction affine :tp-math:`f: f(x) = ax + b`{} (:tp-math:`a`{} et :tp-math:`b`{} constantes) a pour dérivée <tp-blank></tp-blank>.

Solution
:
  1. Une fonction est constante sur l'intervalle :tp-math:`I`{} :tp-math:`\LeftRightarrow`{} sa dérivée est nulle sur :tp-math:`I`{}.

  2. Une fonction affine :tp-math:`f: f(x) = ax + b`{} (:tp-math:`a`{} et :tp-math:`b`{} constantes) a pour dérivée :tp-math:`f'(x) = a`{}.
