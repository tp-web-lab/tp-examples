Solution
:
  1. Une fonction est constante sur l'intervalle :tp-math:`I`{} :tp-math:`\Leftrightarrow`{} sa dérivée est nulle sur :tp-math:`I`{}.

  2. Une fonction affine :tp-math:`f: f(x) = ax + b`{} (:tp-math:`a`{} et :tp-math:`b`{} constantes) a pour dérivée :tp-math:`f'(x) = a`{}.

  3. Pour :tp-math:`n`{} entier naturel non nul, la fonction puissance :tp-math:`f: f(x) = x^n`{} est dérivable sur :tp-math:`\mathbb{R}`{} et sa dérivée est :tp-math:`f'(x) = nx^{n-1}`{}.

  4. Pour :tp-math:`n`{} entier strictement négatif, la fonction puissance :tp-math:`f: f(x) = x^n`{} est dérivable sur :tp-math:`\mathbb{R^*}`{}.

     Cas particulier : la fonction :tp-math:`\displaystyle f(x) = \frac{1}{x}`{} est un fonction puissance (:tp-math:`= x^n`{}) avec :tp-math:`n = -1`{} dont la dérivée est :tp-math:`\displaystyle f'(x) = -\frac{1}{x^2}`{}.

  5. La fonction racine carrée :tp-math:`f: f(x)=\sqrt{x}`{} est définie sur :tp-math:`\mathbb{R^+}`{}, dérivable sur :tp-math:`\mathbb{R^{*+}}`{} et :tp-math:`\displaystyle f'(x) = \frac{1}{2\sqrt{x}}`{}.

  6. Les fonctions trigonométriques :tp-math:`f(x) = \sin(x)`{} et :tp-math:`g(x) = \cos(x)`{} ont pour dérivées respectives :tp-math:`f'(x) = \cos(x)`{} et :tp-math:`g'(x) = -\sin(x)`{}.
